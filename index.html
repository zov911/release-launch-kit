CLI

Run it on your repo. Uses Claude for polished copy when ANTHROPIC_API_KEY is set.

npx github:zov911/release-launch-kit \
  --from CHANGELOG.md

From git or GitHub

Conventional commits since the last tag, or any public release.

launch-kit --from git:v2.3.0..HEAD
launch-kit --from github:owner/repo@latest

GitHub Action

Generate the kit automatically on every release.

- uses: zov911/release-launch-kit@v1
  with:
    from: github:${{ github.repository }}@${{ github.ref_name }}
